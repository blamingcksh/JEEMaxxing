[1] pomodoro.js:438 — transitionToStudy() never resets timerEndTriggered
    Session 2+ never ends. Break end sets the flag true (L296), so the
    study end condition `secondsLeft <= 0 && !timerEndTriggered` (L295)
    can never fire. Timer hangs at 00:00 forever while studySecs keeps
    inflating every tick (no bell, no break, no session advance).
    Trigger: Study → Break → Study (any 2nd study session).
    Fix: set timerEndTriggered = false inside transitionToStudy().

[2] pomodoro.js:499-519 — pause/resume restarts countdown at FULL duration
    pauseTimer() only clears the interval (for countdown modes it stores
    nothing); resumeTimer() resets timerStartTime = Date.now() so the
    next tick computes secondsLeft = timerTotalSeconds - ~0 = full time.
    Trigger: pause a 50-min session with 40:00 remaining → resume shows 50:00.
    Fix: track a paused elapsed offset (same approach as the STOPWATCH
    branch which accumulates correctly at L506-508).

[3] index.html:354 + matrix.js:1048 — ⚡ Daily Fix Queue button is DEAD
    toggleDailyQueue() is exported from matrix.js but never imported into
    app.js and never assigned to window. Inline onclick resolves in
    global scope → clicking throws "ReferenceError: toggleDailyQueue is
    not defined". The entire Daily Core Queue feature is unreachable.
    Fix: import it in app.js and add window.toggleDailyQueue = toggleDailyQueue.

[4] index.html:487 + storage.js:1040 — 📦 Cache All Images Locally is DEAD
    cacheAllDriveImages() is imported into app.js (app.js:27) but never
    attached to window → clicking throws ReferenceError. The offline
    image-cache feature cannot be invoked from the UI.
    Fix: add window.cacheAllDriveImages = cacheAllDriveImages.

[5] sw.js:95 — Installed PWA fails to open offline
    The fetch handler early-returns any same-origin path containing "."
    that isn't .js/.css/.png/.webmanifest/.ico — which includes
    /index.html (the manifest start_url). The pre-cached shell entry
    (sw.js:14) can therefore never be served. Airplane mode + app icon
    = network error. Contradicts the header's "keeps working offline".
    Fix: allow .html in the regex or handle event.request.mode === 'navigate'.
